# 🎙️ Guide - Création des Canaux Vocaux

## Canaux Vocaux à Créer Manuellement

Le bot ne crée pas automatiquement les canaux vocaux. Voici comment les créer sur Discord.

---

## 📋 Liste des Canaux Vocaux

### 1. 🏢 Bureau Admin
**Catégorie :** 🛠️ MANAGEMENT  
**Accès :** Admins uniquement  
**Utilisation :** Réunions privées admins, discussion stratégie

### 2. 📞 Réunion
**Catégorie :** N'importe où (ou créer 🎙️ SALONS VOCAUX)  
**Accès :** Rookie et au-dessus  
**Utilisation :** Réunions communautaires, briefings, formations

### 3. 💬 Salon Communautaire
**Catégorie :** N'importe où (ou créer 🎙️ SALONS VOCAUX)  
**Accès :** Tout le monde  
**Utilisation :** Discussion libre, chill, brainstorming

---

## 🛠️ Étapes de Création

### Option 1 : Créer Catégorie Vocale (Recommandé)

**1. Créer la catégorie**
1. Clic droit sur ton serveur Discord
2. `Créer une catégorie`
3. Nomme-la : `🎙️ SALONS VOCAUX`
4. Valide

**2. Créer les 3 canaux vocaux**

Pour chaque canal :
1. Clic droit sur la catégorie `🎙️ SALONS VOCAUX`
2. `Créer un salon`
3. Sélectionne **Salon vocal** (pas textuel)
4. Entre le nom (voir ci-dessous)
5. Valide

**Noms exacts :**
- `🏢 Bureau Admin`
- `📞 Réunion`
- `💬 Salon Communautaire`

---

### Option 2 : Créer dans Catégories Existantes

**Bureau Admin** → Dans `🛠️ MANAGEMENT`  
**Réunion** → Dans `🌱 CROISSANCE COMMUNAUTÉ`  
**Salon Communautaire** → Dans `📢 BIENVENUE`

Même processus de création que ci-dessus.

---

## 🔐 Configuration des Permissions

### 🏢 Bureau Admin (Admins Seulement)

1. Clic droit sur le canal `🏢 Bureau Admin`
2. `Modifier le salon`
3. Va dans `Permissions`
4. **Désactiver pour @everyone :**
   - ❌ Voir le salon
   - ❌ Se connecter
5. **Activer pour @Admin Farmer League :**
   - ✅ Voir le salon
   - ✅ Se connecter
   - ✅ Parler
   - ✅ Vidéo
   - ✅ Partager l'écran
6. Sauvegarde

---

### 📞 Réunion (Rookie et Au-Dessus)

1. Clic droit sur `📞 Réunion`
2. `Modifier le salon`
3. `Permissions`
4. **Désactiver pour @everyone :**
   - ❌ Se connecter
5. **Activer pour chaque rôle monteur :**
   - @Rookie ✅
   - @Hustler ✅
   - @Grinder ✅
   - @Elite ✅
   - @Admin Farmer League ✅
   - @Modérateur ✅

**Permissions :**
- ✅ Voir le salon
- ✅ Se connecter
- ✅ Parler
- ✅ Vidéo
- ✅ Partager l'écran

6. Sauvegarde

---

### 💬 Salon Communautaire (Tout le Monde)

1. Clic droit sur `💬 Salon Communautaire`
2. `Modifier le salon`
3. `Permissions`
4. **Activer pour @everyone :**
   - ✅ Voir le salon
   - ✅ Se connecter
   - ✅ Parler
   - ✅ Vidéo
   - ✅ Partager l'écran
5. Sauvegarde

---

## ⚙️ Paramètres Recommandés

### Limite d'Utilisateurs

**🏢 Bureau Admin :** 5 max (réunions intimes)  
**📞 Réunion :** 25 max (conférences)  
**💬 Salon Communautaire :** Illimité  

**Comment faire :**
1. Modifier le salon
2. Va dans `Aperçu`
3. `Limite d'utilisateurs` → Définis le nombre
4. Sauvegarde

---

### Région Vocale

**Optimale :** `Europe` (ou la région la plus proche de ta majorité de membres)

**Comment faire :**
1. Modifier le salon
2. `Aperçu`
3. `Région de serveur vocal` → Choisis `Europe`
4. Sauvegarde

---

### Qualité Audio

**🏢 Bureau Admin :** 96 kbps (normal)  
**📞 Réunion :** 96 kbps (normal)  
**💬 Salon Communautaire :** 64 kbps (économie)  

**Comment faire :**
1. Modifier le salon
2. `Aperçu`
3. `Débit binaire` → Choisis la qualité
4. Sauvegarde

---

## 🎬 Activation Caméra/Écran

Pour chaque salon vocal, assure-toi que ces permissions sont activées :

✅ **Vidéo** - Activer la webcam  
✅ **Activité** - Voir qui est en train de parler  
✅ **Partager l'écran** - Screenshare
