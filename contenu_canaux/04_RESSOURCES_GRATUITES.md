## 💡 Tips & Tricks du Jour

**Astuce Raccourci Clavier Premiere**
```
J / K / L = Rewind / Pause / Play
(très utile pour sync précise)
```

**Astuce Transition Smooth**
```
Whip pan + Motion blur = Transition ultra pro
Sans plugin nécessaire
```

**Astuce Color Grading**
```
Règle 60-30-10
60% teintes neutres
30% couleur secondaire
10% couleur accent
= Look équilibré
```

**Astuce Rythme**
```
Change de plan toutes les 2-3 secondes max
pour clips courts (TikTok/Reels style)
Attention du viewer = 3 sec max
```
